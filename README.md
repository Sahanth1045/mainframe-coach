# Mainframe Interview Coach

Design a Premium Mainframe AI Interview Platform

Create a modern, premium, production-quality web application for a platform called Mainframe Interview Coach.

The product helps experienced and aspiring mainframe developers prepare for technical interviews using AI.

This is NOT a generic AI chatbot, NOT a generic LMS, and NOT a basic quiz website.

The visual quality should feel comparable to a polished modern SaaS product such as Linear, Vercel, Notion, Stripe, or high-end developer tools — while still being approachable for professionals who work with enterprise/mainframe technology.

1. PRODUCT PURPOSE

The platform helps a user:

Assess their current mainframe knowledge

Identify weak areas

Learn important concepts

Practice interview questions

Take realistic AI-powered mock interviews

Receive detailed AI feedback

Track improvement over time

Prepare specifically for mainframe developer interviews

The core experience should make the user feel:

"This platform understands mainframe interviews and is actively helping me become interview-ready."

Avoid making it feel like a collection of disconnected features.

2. PRIMARY PRODUCT AREAS

The application should have these major areas:

Dashboard

The user's command center.

AI Mock Interview

The core product experience.

Practice

Topic-based interview questions and exercises.

Learning

Structured learning paths for mainframe technologies.

Progress

Performance analytics and improvement tracking.

Interview History

Previous mock interviews, scores and feedback.

Profile / Settings

User account and preferences.

13. ANSWER EXPERIENCE

30. TEMPLATE EXPLORATION

For this first version, focus primarily on finding the best overall visual direction and application structure.

Explore several possible layouts before committing.

Consider:

Direction A — Premium Developer SaaS

Inspired by Linear / Vercel / modern developer tools.

Direction B — Premium EdTech

Modern learning platform with strong progress and learning visualization.

Direction C — AI Career Coach

More conversational, centered around the AI interviewer and personalized coaching.

Direction D — Enterprise Professional

More restrained, structured and professional, suitable for experienced enterprise developers.

You may combine the strongest aspects of these directions.

31. MOST IMPORTANT DESIGN PRIORITY

The AI Mock Interview screen should be the centerpiece of the product.

When a user enters the interview, the experience should feel significantly more sophisticated than:

"Question → Text box → Submit."

It should feel like:

A real professional interviewer is sitting across from you.

The AI should appear intelligent, focused and evaluative.

The candidate should always understand:

What is being asked

What type of question it is

How they are performing

What happens next

How much of the interview remains

32. FINAL DESIGN QUALITY BAR

Before finalizing the design, evaluate every page against these questions:

Does this look like a real commercial SaaS product?

Does it look better than a typical AI-generated dashboard?

Is the hierarchy immediately clear?

Is there unnecessary decoration?

Does every element have a purpose?

Is the typography professional?

Are spacing and alignment consistent?

Does the product feel cohesive from page to page?

Does the mock interview feel like the core product?

Would a professional mainframe developer trust this platform?

If something looks like a generic template, redesign it.

IMPORTANT

For this stage, prioritize visual exploration and UX quality over backend implementation.

Create a polished, realistic frontend prototype with realistic sample data.

Use realistic mainframe interview content instead of generic placeholder text such as "Lorem ipsum" or "Sample Question".

The final result should look like a real product that could be launched, not a UI concept or hackathon prototype.
